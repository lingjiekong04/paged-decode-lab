# 公开范围、来源与剩余缺口

本候选目录由本次远程只读采集构建；根别名remote-project对应私有审查记录中的确认目录。远程不是Git仓库，因此无可报告的项目HEAD；固定nano-vLLM上游commit真实存在于原项目manifest。725个采集文件的原始SHA256保留在provenance中，绝对服务器路径不公开。

| 决定 | 内容 | 理由／处理 |
|---|---|---|
| 保留 | 核心src、必要工具和测试、配置、补丁、算法快照 | 保持可检查的依赖链，继承文件字节不为排版而改写 |
| 保留 | 6份上游修改文件覆盖层、上游LICENSE、固定manifest | 通过哈希验证基线加覆盖层重建，不重复分发完整上游 |
| 保留 | 派生计时记录、数值摘要、可重算summary、结果图 | 提供公开可检查的结论；保留原证据SHA及提取规则 |
| 排除 | 权重、虚拟环境、wheel、缓存、cubin、KV激活.pt | 大型资源、环境绑定或不必要的原始内容 |
| 排除 | 原始日志、GPU UUID、PID监控、服务器路径、生成响应 | 仅供私有审核，不自动公开 |
| 排除 | 历史完整ZIP、旧安装／调度shell脚本 | 重复且绑定原环境；原项目保持不变 |

| 外链 | nano-vLLM、官方Qwen、Triton／FA论文与文档 | 固定基线和模型revision见机器配置；模型链接本次未重下载验证 |
| 待核验 | 新机器依赖安装、在线模型可访问性、所有上游许可更新 | 本次不安装系统依赖、不启动GPU；用户实际使用时确认 |

本次盘点扫描5857文件、2438308723B，无读取失败；模型／环境／缓存等被排除，不能称为完整项目总大小。第一轮目录规则误将nano-vLLM源码models子目录排除，随后独立v2盘点补齐；v1保留私有记录，采集采用v2。私有白名单725文件、10902819B；与旧本地同路径逐项比对均一致，没有混合不同版本。

当前能证明代码与原字节对应、基线可离线重建、公开统计可重算以及CPU检查可执行。历史GPU／模型结果由现存远程文件支持，本轮未重跑。没有真实业务验证、吞吐SLA、服务部署或生产可用验收。

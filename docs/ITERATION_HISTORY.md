# 真实迭代历史

阶段名称是按远程现存源码、快照和报告整理的标签，不是虚构的Git release。本次主目录没有Git元数据；归因采用路径、上游commit与SHA256，不伪造项目提交历史。每行使用各阶段自己的验收集，不能拼成统一提速曲线。

## 核心算法

| 阶段 | 相比前版变化 | 解决的问题 | 如何验证 | 最终采用 |
|---|---|---|---|---|
| 基础paged decode | 显式分页读取、online softmax | 正确访问非连续KV | FP32参考和边界测试 | 保留教学／消融 |
| 固定1024 split-K | 并行分区＋稳定m/l/a合并 | 小batch长序列并行度不足 | 算子及模型回归；存在历史argmax分歧 | 保留显式后端 |
| Tensor Core ordered | BF16 QK/PV、四状态保序分母 | 数值协议与吞吐 | 多候选比较；v2-gather编译失败后修正 | integrated实现保留 |
| TC split-K | Tensor Core结合固定1024分区 | 进一步拆分长序列 | 短提示通过，9B长输入失败 | 保留实验边界 |
| matched v1→v2 | 容量规划、normalized partial/LSE、快速log | 本地LSE舍入导致token分歧 | 真实激活因果诊断＋完整logits | v2集成，v1快照保留 |
| warps／late V／IR分析 | 显式4/8warps、移动V加载、检查布局与存活 | 定位D64/128额外开销 | 独立对照和编译IR；部分计时不收敛 | 诊断，不宣称全部有效 |
| 四状态shared微内核 | 根据MMA片段维持有序归约 | 减少有序分母长依赖与临时量 | 实际槽位探测、FMA修正、分页partition回归 | 实验保留 |
| D256扩展shared_s3 | 扩展D256真实模型几何 | 覆盖Qwen3.5 full attention | 模型正确性与性能；长上下文退化 | 对照保留 |
| shared_s2 | stages3→2，减少dynamic shared | 恢复驱动双CTA驻留上限 | 72输出、两模型回归、480+160计时 | 显式实验；不全局替换 |
